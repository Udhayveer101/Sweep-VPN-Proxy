Gaming
Gaming mode
Disguise
Routes the whole PC, games included, through WARP at the packet level, so traffic games send over UDP is carried too — the proxy mode below cannot do that. Needs administrator rights (Windows asks), and turns the proxy mode off while it runs. Reconnecting on drops rebuilds the tunnel each time the network drops it, in about a second, and is the right choice for games. Rotating flows retires each tunnel before the network can drop it, but measured cost is a stall every minute or two — fine for downloads, bad for a game. Change the disguise with gaming mode off.

Route this whole PC through WARP
Starts WARP and sets the Windows proxy to it. Edge, Chrome, Firefox on default settings and most apps follow it; apps that ignore the system proxy — and UDP, which most games use — are unaffected (that is what gaming mode is for). Sweep puts your own proxy settings back when you turn this off, quit, or after a crash.
WARP SNI

Set up Sweep VPN

About a minute, and only once. Follow the steps in order.

What you need

Nothing to buy and no account to create. Sweep's proxy runs on Cloudflare WARP, which is free. You only need an internet connection for the next step.
